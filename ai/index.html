AI in CityLore

How CityLore marks text an AI wrote, and how anyone can check it. Deutsche Fassung weiter unten.

Where an AI writes

In the web editor at app.citylore.app, creators can have an AI draft a whole tour, or write one stop again. The AI is Claude, by Anthropic. The creator reads and edits everything before anyone else sees it. A tour stays private until its creator shares it with people they invite or makes it public.

How AI text is marked

  • A watermark in the text. Claude puts an invisible watermark into the text it writes. It travels with the text when it's copied, and can fade when the text is heavily edited. Anthropic explains it.
  • A signed note in the tour. Each AI draft and each rewritten stop adds a note to the tour, signed by CityLore's server. The note lists a fingerprint of every text the AI wrote, the model, the time, and the account it was written for.
  • A plain flag. Every tour says whether an AI drafted any part of it, with which model and when.
  • The creator's fact check. Before a tour with AI-written text goes public, its creator confirms they checked its facts and answers for what it says. They confirm again when new AI text goes into a public tour.

The EU's AI Act asks services that generate text to mark it in a way software can read (Article 50). The tour pages show no AI badge: the creator decides what a tour says, and answers for it.

Checking a note

Tours are records of the type app.citylore.tour on the open social web (ATProto). Their notes are in provenance.notes. Each note has:

  • texts: for each text the AI wrote, where it is (stop, the stop's id, absent for the tour's title and summary; field, such as story or clue.riddle) and sha256, the SHA-256 of the text as written (UTF-8), base64url without padding;
  • model, writtenAt and account;
  • key: did:web:app.citylore.app#ai_notes. Its public key is in our DID document: P-256, zDnaey4eK7fsrg29HP4AsuXyJougW8YMxHTwctPcNPsuMpy2U;
  • sig: the signature, base64url without padding.

The signature covers the UTF-8 bytes of the JSON array ["citylore-ai-note/1", key, account, model, writtenAt, [[stop or "", field, sha256], …]], with the note's own values in that order. It is ECDSA P-256 over SHA-256, 64 bytes (r and s, low-S), as ATProto signs. In JavaScript, with @atproto/crypto:

import { verifySignature } from "@atproto/crypto";

const PUBLIC_KEY = "did:key:zDnaey4eK7fsrg29HP4AsuXyJougW8YMxHTwctPcNPsuMpy2U";

async function checkNote(note) {
  const { sig, ...rest } = note;
  const signed = ["citylore-ai-note/1", rest.key, rest.account, rest.model, rest.writtenAt,
    rest.texts.map((t) => [t.stop ?? "", t.field, t.sha256])];
  const bytes = new TextEncoder().encode(JSON.stringify(signed));
  return verifySignature(PUBLIC_KEY, bytes, Buffer.from(sig, "base64url"));
}

async function fingerprint(text) {
  const hash = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(text));
  return Buffer.from(hash).toString("base64url");
}

Then compare each text's sha256 with the fingerprint of the text the tour has now. A match means the text is exactly as the AI wrote it. No match means someone changed it since, but an AI wrote it first.

What a check can't tell

  • A tour without a note may still contain AI text, written elsewhere and pasted in.
  • A watermark is a signal, not proof: very short or heavily edited text may not carry one.
  • A note shows that an AI wrote a text, not that the text is right. The creator's fact check is what stands behind it.

KI in CityLore

Wie CityLore Text kennzeichnet, den eine KI geschrieben hat, und wie alle das prüfen können.

Wo eine KI schreibt

Im Web-Editor auf app.citylore.app können Autorinnen und Autoren eine ganze Tour von einer KI entwerfen oder eine Station neu schreiben lassen. Die KI ist Claude von Anthropic. Die Autorin oder der Autor liest und bearbeitet alles, bevor jemand anderes es sieht. Eine Tour bleibt privat, bis sie mit eingeladenen Personen geteilt oder veröffentlicht wird.

Wie KI-Text gekennzeichnet ist

  • Ein Wasserzeichen im Text. Claude setzt ein unsichtbares Wasserzeichen in den Text, den es schreibt. Es geht beim Kopieren mit und kann verblassen, wenn der Text stark bearbeitet wird. Anthropic erklärt es (englisch).
  • Eine signierte Notiz in der Tour. Jeder KI-Entwurf und jede neu geschriebene Station fügt der Tour eine Notiz hinzu, die der Server von CityLore signiert. Die Notiz nennt einen Fingerabdruck jedes Texts, den die KI geschrieben hat, das Modell, die Uhrzeit und das Konto, für das er geschrieben wurde.
  • Ein einfaches Kennzeichen. Jede Tour sagt, ob eine KI einen Teil davon entworfen hat, mit welchem Modell und wann.
  • Die Faktenprüfung. Bevor eine Tour mit KI-geschriebenem Text öffentlich wird, bestätigt die Autorin oder der Autor, die Fakten geprüft zu haben und für den Inhalt einzustehen. Kommt neuer KI-Text in eine öffentliche Tour, bestätigen sie es erneut.

Die KI-Verordnung der EU verlangt von Diensten, die Text erzeugen, ihn so zu kennzeichnen, dass Software es lesen kann (Artikel 50). Die Tourseiten zeigen kein KI-Abzeichen: Was eine Tour sagt, entscheidet ihre Autorin oder ihr Autor und steht dafür ein.

Eine Notiz prüfen

Touren sind Einträge vom Typ app.citylore.tour im offenen sozialen Netz (ATProto). Ihre Notizen stehen in provenance.notes. Jede Notiz hat:

  • texts: für jeden Text, den die KI geschrieben hat, wo er steht (stop, die Kennung der Station, fehlt bei Titel und Zusammenfassung der Tour; field, etwa story oder clue.riddle) und sha256, den SHA-256 des Texts wie geschrieben (UTF-8), base64url ohne Auffüllung;
  • model, writtenAt und account;
  • key: did:web:app.citylore.app#ai_notes. Sein öffentlicher Schlüssel steht in unserem DID-Dokument: P-256, zDnaey4eK7fsrg29HP4AsuXyJougW8YMxHTwctPcNPsuMpy2U;
  • sig: die Signatur, base64url ohne Auffüllung.

Die Signatur gilt für die UTF-8-Bytes des JSON-Arrays ["citylore-ai-note/1", key, account, model, writtenAt, [[stop oder "", field, sha256], …]] mit den Werten der Notiz in dieser Reihenfolge. Sie ist ECDSA P-256 über SHA-256, 64 Bytes (r und s, low-S), wie ATProto signiert. Ein Beispiel in JavaScript steht oben in der englischen Fassung.

Danach den sha256 jedes Texts mit dem Fingerabdruck des Texts vergleichen, den die Tour jetzt hat. Stimmen sie überein, steht der Text genau so da, wie die KI ihn geschrieben hat. Stimmen sie nicht überein, hat ihn seitdem jemand geändert, aber zuerst hat ihn eine KI geschrieben.

Was eine Prüfung nicht sagen kann

  • Eine Tour ohne Notiz kann trotzdem KI-Text enthalten, der anderswo geschrieben und eingefügt wurde.
  • Ein Wasserzeichen ist ein Hinweis, kein Beweis: Sehr kurzer oder stark bearbeiteter Text trägt es vielleicht nicht.
  • Eine Notiz zeigt, dass eine KI einen Text geschrieben hat, nicht, dass er stimmt. Dafür steht die Faktenprüfung der Autorin oder des Autors.
